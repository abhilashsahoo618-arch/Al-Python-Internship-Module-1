
# Difference Between AI, ML and Deep Learning

## 1. Artificial Intelligence (AI)

Artificial Intelligence is a branch of computer science that enables machines to perform tasks that normally require human intelligence.

Examples:
- ChatGPT
- Google Assistant
- Self-driving cars
- Face recognition

## 2. Machine Learning (ML)

Machine Learning is a subset of Artificial Intelligence that allows computers to learn from data and improve their performance without being explicitly programmed for every task.

Examples:
- Email spam detection
- Netflix recommendations
- Fraud detection
- Weather prediction

## 3. Deep Learning (DL)

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers to learn complex patterns from large amounts of data.

Examples:
- Face recognition
- Voice recognition
- Image classification
- Self-driving car technology

## Difference Between AI, ML and DL

| Artificial Intelligence | Machine Learning | Deep Learning |
|---|---|---|
| Broad field of computer science | Subset of AI | Subset of ML |
| Makes machines intelligent | Learns from data | Uses neural networks |
| Can use different techniques | Uses algorithms to learn | Learns complex patterns |
| Example: Smart assistants | Example: Spam detection | Example: Image recognition |

## Conclusion

AI, ML and Deep Learning are closely related technologies. AI is the broad concept, ML is a part of AI, and Deep Learning is a specialized part of ML.
